Intuition anzeigen

Injektiv: Keine zwei Punkte landen am selben Ort. Surjektiv: Jeder Punkt in Y wird getroffen.

Beispiel oder Gegenbeispiel?

  • f : ℝ → ℝ, f(x) = x²
  • f : ℝ → ℝ, f(x) = 2x + 1
  • f : ℝ → [0, ∞), f(x) = x²
